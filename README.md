# Marketing Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end marketing analytics workflow using campaign performance data from multiple advertising platforms.

The objective was to consolidate marketing data, perform data validation, create a unified reporting dataset, and build an interactive dashboard for performance analysis.

---

## Tools Used

* SQL
* Google BigQuery
* Looker Studio
* Microsoft Excel

---

## Project Workflow

### Data Sources

* Facebook Ads
* Google Ads
* TikTok Ads

### Data Validation

Validated source datasets for:

* Missing values
* Data consistency
* Campaign-level accuracy
* Metric completeness

### Data Modeling

Created a unified marketing dataset by combining platform-specific tables into a single reporting layer.

Key fields:

* Platform
* Date
* Campaign ID
* Campaign Name
* Impressions
* Clicks
* Cost
* Conversions

### Dashboard Development

Built an interactive dashboard to analyze:

* Total Spend
* Impressions
* Clicks
* Conversions
* Campaign Performance
* Platform Performance Trends
